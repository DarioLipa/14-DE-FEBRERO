# 🎁 Regalo Interactivo de San Valentín – Luis ❤️ Yamileth

![Novios GIF](https://media.giphy.com/media/3o7aD2saalBwwftBIY/giphy.gif)

**Fecha de creación:** 10/10/2022

Este proyecto es una aplicación web interactiva diseñada como un regalo romántico para celebrar el amor. Está construida con **HTML**, **CSS** y **JavaScript puro**, sin dependencias externas, ofreciendo una experiencia fluida y visualmente impactante.

## ✨ Características principales

- Contador de aniversario que muestra años, meses y días juntos.
- Galería de recuerdos con efecto hover y lightbox para ampliar fotos.
- Carta sorpresa con animación 3D y texto personalizado.
- Reproductor de música estilo vinilo con visualizador Canvas.
- Cupones interactivos y confetti al canjearlos.
- Modo oscuro y partículas de corazones flotantes.
- Diseño responsivo con glass‑morphism para una estética premium.

## 📋 Menús y secciones del Dashboard

- **Inicio** – Contador de aniversario y mensaje de bienvenida.
- **Recuerdos** – Galería de fotos con descripciones al pasar el cursor y zoom al hacer clic.
- **Línea de tiempo** – Cronología visual de momentos importantes.
- **Canciones** – Reproductor de vinilo con visualizaciones de audio.
- **Cupones** – Tarjetas canjeables con confetti y efectos especiales.
- **Carta** – Sobre 3D que se abre revelando una carta de amor con texto emotivo.
